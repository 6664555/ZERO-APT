# Security Policy

## Responsible Use

ZERO-APT automates post-exploitation actions and ships an action library derived from [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team). It exists for **authorized security research, education, and defense validation on custom testbeds only**.

You may use this project **only** against systems you own or have explicit written authorization to test — for example, isolated lab VMs and purpose-built ranges such as the one described in the ZERO-APT paper.

**Do not** use it against real systems, production networks, or any third-party target. It is **not** intended for real-world use. Misuse may violate local and international law, and you alone are responsible for how you use it.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability. Report it privately to the maintainers (see the corresponding author contact in the paper), and we will respond as soon as possible.
